* Pointers: used pointers in order to reference objects made by the "new" keyword as well as in parameters.
* Const: used const to keep integrity of parameters and variables that should not be changed.
* References: used in parameters to pass by reference and not create a copy.
* Casting: used 'static_cast<int>' to change double to int.
* Exceptions: used to catch errors without crashing.
* Control-flow: used do-while, switch, and if-else statements in the program.
